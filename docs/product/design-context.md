# 잼얘좀 디자인 컨텍스트

## 제품

- 폐쇄형 그룹에서 주제를 만들고 실시간으로 대화하는 소셜 채팅 PWA
- 데스크톱 웹 브라우저와 iOS·Android 모바일 브라우저를 함께 지원
- 모바일 우선으로 설계하되 데스크톱에서는 넓은 화면을 활용하는 적응형 구조 필요

## 언어

- 한국어 전용
- 기본 서체는 Pretendard
- 한국어 문장 길이와 줄바꿈을 기준으로 타이포그래피와 컴포넌트 폭 설계

## 주요 사용자와 관계

- 친한 친구와 지인으로 이루어진 소규모 폐쇄 그룹
- 공개 커뮤니티의 탐색·과시보다 빠른 참여, 친밀감, 대화의 연속성을 우선
- 서로를 이미 아는 사용자가 일상적으로 짧고 자주 접속하는 상황을 중심으로 설계

## 브랜드 성격

- 장난스럽고 재치 있는 친근한 브랜드
- 재미는 포인트 색상, 마이크로카피, 상태 표현과 작은 상호작용에서 드러냄
- 장시간 대화 화면의 가독성과 안정성을 해치지 않도록 장식은 절제

## 미적 방향

- 부드러운 파스텔을 사용하는 밝고 친근한 분위기
- 둥근 표면, 은은한 색면, 낮고 일관된 elevation을 사용
- 파스텔은 배경·배지·선택 상태에 집중하고 본문 텍스트는 WCAG 대비를 유지
- 다크 모드는 단순 반전 대신 채도와 명도를 조정한 별도 파스텔 톤으로 설계

## 확정한 디자인 방향

- B안 `파스텔 대화 보드`를 최종 방향으로 선택
- 모바일은 한 번에 하나의 대화 흐름에 집중하고, 데스크톱은 그룹 레일·중앙 대화·선택형 컨텍스트 패널로 확장
- Setlog의 따뜻한 종이 질감과 친구 중심 정서는 유지하되, 핵심 오브젝트를 영상이 아닌 텍스트 주제 카드로 전환
- daisyUI 커스텀 테마 이름은 `jamye-light`, `jamye-dark`로 정의하고 기본 테마와 시스템 다크 모드 자동 추종을 유지

## 현재 기술·디자인 기반

- Svelte 5, SvelteKit, Tailwind CSS 4, daisyUI 5.6.x
- daisyUI `light --default`, `dark --prefersdark` 시스템 테마 추종
- Lucide 아이콘과 daisyUI 의미 색상 토큰 사용
- 모바일 safe area, PWA standalone, reduced motion 지원 유지

## 모션 방향

- CSS와 daisyUI 상태 전환을 우선하고, DOM 진입·퇴장과 작은 keyed 목록 재배치에는 Svelte 네이티브 모션을 사용
- 기본 프리미티브는 `fade`, `fly`, `scale`, 제한적인 `animate:flip`이며 `Spring`과 `Tween`은 한두 개의 연속 값에만 사용
- GSAP과 범용 애니메이션 런타임은 현재 제품 범위에서 제외
- 공간 이동은 transform과 opacity 중심으로 150-200ms 안에 끝내고, 300ms는 온보딩·빈 상태의 일회성 강조에만 사용
- Svelte 모션은 전역 CSS 규칙에만 기대지 않고 `prefersReducedMotion.current`를 직접 반영
- 채팅 스크롤 앵커, composer 크기·위치, safe area, 키보드 보정, Embla가 소유한 transform은 애니메이션하지 않음
- iOS Safari/PWA와 Android Chrome/PWA 실제 기기에서 키보드, 스크롤, 백그라운드 복귀, reduced motion을 함께 검증

## 보존할 동작

- 채팅 스크롤 앵커, 낙관적 메시지 전송, IME 입력 처리
- iOS PWA 키보드 전환은 브라우저 제약 안에서 정착 상태를 우선하는 best-effort 방식

## Reference Sites

- [setlog.kr](https://setlog.kr): 친한 친구 중심의 사적이고 장난스러운 분위기, 미색 캔버스, 파스텔 윤곽선, 큰 라운드 카드, 손그림 낙서와 즉각적인 반응 표현을 참고
- [Setlog App Store](https://apps.apple.com/kr/app/setlog/id6587576438): 실제 모바일 화면 구조와 친구 중심 제품 감각 참고

## Setlog 번역 원칙

- 영상 중심 로그 피드는 복제하지 않고 `텍스트 주제 카드 → 친구 반응 → 실시간 채팅` 흐름으로 번역
- 미색 바탕, 파스텔 포인트, 유기적인 라운드, 스티커 같은 장식 리듬은 활용
- 손글씨·디스플레이 서체는 로고나 짧은 강조에만 참고하고 본문은 Pretendard 유지
- 낙서와 스티커는 장식으로만 사용하며 구조적 아이콘은 Lucide로 유지
- Setlog의 제스처·카메라 중심 인터랙션은 가져오지 않음

## 접근성 목표

- WCAG 2.2 AA 준수
- 일반 텍스트 대비 4.5:1 이상, 큰 텍스트와 주요 UI 그래픽 대비 3:1 이상
- 모든 핵심 기능을 키보드와 스크린 리더로 이용 가능하게 설계
- 터치 대상은 최소 44×44px, 인접 대상 사이에는 충분한 간격 확보
- 색상만으로 상태를 전달하지 않고 아이콘·텍스트·형태를 함께 사용
- `prefers-reduced-motion`과 확대된 글자 크기에서 레이아웃 유지
